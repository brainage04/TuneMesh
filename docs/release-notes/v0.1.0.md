First public release of Spotless, a music player for a library that
Syncthing keeps in sync between Linux computers and Android phones, with a
downloader for YouTube, YouTube Music and Spotify links.

## Switching from TuneMesh

Spotless was called TuneMesh before this release. It does not migrate
anything from TuneMesh: the package names, the Android application ID, the
Syncthing folder ID (`spotless`), the settings folders and the library's
state folder (`.spotless/`) all changed, so the two can be installed side by
side and neither sees the other. Set Spotless up as on a new device, and
switch every device in one go:

1. **Finish or note pending downloads.** Spotless does not read TuneMesh's
   download requests (`<library>/.tunemesh/requests/`) or their history. Let
   the TuneMesh worker finish them, or write down the links that are still
   waiting and request them again in Spotless.
2. **Stop the TuneMesh downloader** on the computer that ran it:
   `systemctl --user disable --now tunemesh-worker` (on NixOS, remove
   `services.tunemesh-worker` or the `systemd.user.services.tunemesh-worker`
   line from the configuration). Left running, it keeps downloading for
   TuneMesh devices and writing into `Playlists/`, while Spotless shows "No
   device is downloading right now".
3. **Uninstall TuneMesh** on every device. Its packages have other names, so
   installing Spotless does not replace them:

   | Installed with | Remove |
   | --- | --- |
   | `.deb` | `sudo apt purge tunemesh` |
   | `.rpm` | `sudo dnf remove tunemesh` |
   | Arch | `sudo pacman -Rns tunemesh` (or `tunemesh-bin`) |
   | Flatpak | `flatpak uninstall --user --delete-data io.github.brainage04.TuneMesh` |
   | Snap | `sudo snap remove --purge tunemesh` |
   | AppImage | delete `TuneMesh-<version>-<arch>.AppImage` |
   | Nix | `nix profile remove TuneMesh` (the name `nix profile list` shows) |
   | From source | `sudo packaging/linux/install.sh --uninstall`, run from a TuneMesh checkout |
   | Android | uninstall the TuneMesh app (`io.github.brainage04.tunemesh`) |

   Then delete its settings, state, cache and downloader tools:
   `rm -rf ~/.config/tunemesh ~/.local/state/tunemesh ~/.cache/tunemesh ~/.local/share/tunemesh`.
   A NixOS `services.tunemesh-worker` also leaves its work and state
   folders: `sudo rm -rf /var/cache/tunemesh-worker /var/lib/tunemesh-worker`
   (the defaults; use the module's `workDir` and `stateDir` if you changed
   them).
4. **Remove the `tunemesh` folder in Syncthing on every device**, the phone's
   Syncthing included ("Edit" → "Remove"; the files stay on disk). This
   is required when the Spotless library stays in the same place: Syncthing
   cannot share one folder under two folder IDs, and the Spotless setup
   assistant does not check for an old folder on the same path.
5. **Install and set up Spotless** on every device, choosing the existing
   library folder (on the phone: Settings → Library folder), and share it as
   `spotless`. Enable `spotless-worker` on the computer that downloads
   (`systemctl --user enable --now spotless-worker`, or **This device
   downloads songs** in the setup assistant).
6. **Delete `<library>/.tunemesh/`** once no device runs TuneMesh any more.
   Nothing reads it, but Syncthing keeps syncing it until it is gone; delete
   it on one device and Syncthing removes it everywhere.

Songs, playlists and Liked Songs live in the library folder and stay as they
are. What starts empty on every device: its settings, the play queue and
position, the download history, and the playlist merge bases. Without those
bases, a song removed from a playlist on one device can come back the first
time Spotless merges a conflict copy of that playlist; remove it again.
